# dotfiles

Personal configs rooted at `~/.config` (`ZDOTDIR`). macOS, Homebrew, Ghostty, Zed.

## Setup

Claude Code settings are symlinked into the repo:

```sh
ln -sf ~/.config/claude/settings.json ~/.claude/settings.json
```

## What's tracked

- `.zshrc` / `.zprofile` — zsh config
- `ghostty/config` — terminal
- `claude/settings.json` — Claude Code
- `git/ignore` — global gitignore
- `opencode/` — opencode
- `zed/` — Zed editor
